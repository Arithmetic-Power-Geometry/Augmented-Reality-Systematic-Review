# Reproduction Environment Contract

The benchmark must be reproducible from a clean environment.

## Required files before first experimental release

- container/Dockerfile or equivalent environment specification;
- dependency lock files;
- scripts for dataset validation;
- scripts for each method build;
- scripts for each benchmark run;
- common evaluation scripts;
- hardware manifest;
- run manifest;
- checksums for downloaded benchmark metadata where licensing permits.

## Artifact rule

Raw benchmark outputs are immutable inputs to downstream artifact generation.

The pipeline is:

raw outputs → validated run table → statistical summaries → figures/tables

Figures and tables are never hand-edited to alter numeric results.

## Licensing rule

Third-party source code is not copied into this repository unless its license and redistribution terms explicitly permit the intended use. Prefer pinned upstream repositories, documented build scripts, patches, and containers.

## Result provenance

Every plotted point or table cell generated by this project must resolve to:
- run ID(s);
- method commit;
- dataset/sequence;
- configuration;
- hardware/environment;
- evaluator version.

This provenance rule applies before paper drafting.
