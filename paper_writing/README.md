# Paper-Writing Evidence Control

This folder is the manuscript-facing control layer for the AR research programme.

## Purpose

It records what has actually been completed, what analyses are planned, which claims are currently supportable, which claims remain hypotheses, and which repository artifacts/commits support future manuscript sections.

The controlling workbook is **AR_Paper_Writing_Evidence_Control.xlsx**. Because the connected GitHub contents interface currently accepts UTF-8 repository files rather than binary XLSX payloads, the workbook is also mirrored here as manuscript-control CSV files. The XLSX should be uploaded to this folder unchanged when binary repository upload is available.

## Paper programme

- **P1 — Systematic Review:** evidence synthesis, Evidence Cube, C0–C3 comparability, reproducibility and persistent/actionable-gap analysis.
- **P2 — Benchmark-Transfer Study:** controlled SLAM/VIO evidence versus AR-native localization evidence.
- **P3 — Adaptive AR Localization Orchestrator:** candidate method only; novelty claim is prohibited until P2 failure-regime evidence and closest-prior-work audit are complete.

## Writing rule

Literature-reported evidence, repository-generated evidence, hypotheses and proposed methods must remain distinct. No unexecuted benchmark may enter a Results section as a numeric finding. No candidate method may be described as novel before the novelty gate closes.
