# Run 66 — Parallel Screening Progression

## Purpose
TA-01 is now reviewer-ready but cannot be counted as formally screened until genuine primary decisions are recorded. To avoid idle time, Run 66 starts TA-02 in parallel using the same frozen PubMed source, immutable ordinal structure, and nonbinding assistance boundary.

## Scientific boundary
- TA-01: reviewer handoff prepared; official completion remains blocked by genuine decisions.
- TA-02: evidence materialization and assisted prioritization may proceed.
- No assisted state increments the formal screening count.
- Final PRISMA counts remain derived only from versioned genuine decision ledgers.
- The assistance pipeline is treated as prioritization/quality-control infrastructure and is reported separately from human eligibility decisions.

## Paper implication
This parallelization changes workflow efficiency, not eligibility criteria. The same inclusion/exclusion codebook and uncertainty-advances rule apply to every batch.
