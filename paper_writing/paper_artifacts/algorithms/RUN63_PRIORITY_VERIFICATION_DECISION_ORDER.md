# Run 63 — Priority Verification Decision Order

For each Run 62 `PRIORITY_VERIFY` record:

1. **Primary/secondary gate:** commentary, review, editorial or trend overview -> recommend `E-SECONDARY`.
2. **Principal-setting gate:** if the evaluated system is VR or another technology and AR/MR is only future/potential/application context -> recommend `E-VR-ONLY` or `E-NOT-AR`.
3. **Implemented-AR gate:** if the record reports an AR/MR overlay, interface, simulator, navigation, visualization or evaluated technical component materially necessary to AR -> advance.
4. **Missing-abstract gate:** never exclude for missing abstract alone; retrieve/verify the report or advance as uncertain.
5. **Ambiguity rule:** uncertainty advances.
6. **Automation boundary:** recommendations remain separate from `primary_decision` until genuine reviewer confirmation.

This ordering minimizes false-negative exclusions while concentrating human effort on the most informative cases.
