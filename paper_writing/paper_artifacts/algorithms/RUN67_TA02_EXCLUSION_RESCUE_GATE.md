# Run 67 — TA-02 Exclusion Rescue Gate

For every assisted exclusion candidate:

1. Read title and complete available abstract.
2. Test explicit augmented reality, mixed reality, mixed-reality, blended reality, extended reality/XR, AR-based systems, spatial overlays and tracked physical–virtual integration.
3. Distinguish acronym/substring collisions: androgen receptor, adrenergic receptor, acid resistance, autoradiography, argon and words such as “augments”.
4. If AR is explicit and material, recommend ADVANCE.
5. If XR/MR is explicit but AR separability is unresolved, recommend ADVANCE / UNCERTAIN.
6. Only clearly unrelated records remain likely `E-NOT-AR`.
7. Never populate an official primary decision or reviewer identity from this gate.
