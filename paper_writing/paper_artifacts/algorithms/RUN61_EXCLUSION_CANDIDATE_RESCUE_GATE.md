# Run 61 — Exclusion-Candidate Rescue Gate

Input: records proposed as `EXCLUDE_CANDIDATE` by assisted triage.

1. Re-read title and full available abstract.
2. Search explicitly for augmented reality, mixed reality, hyphenated mixed-reality, blended reality, physical–virtual integration, spatial overlays/tracking, and AR-relevant image-guidance context.
3. Distinguish acronym collisions such as adrenergic receptor, androgen receptor, antigen retrieval, acid resistance, automatic registration, argon, and unrelated chemical notation.
4. If AR/MR is explicit and material, mark `ADVANCE`.
5. If AR relevance or separability is plausible but ambiguous, mark `ADVANCE / UNCERTAIN`.
6. Only if the abstract is clearly outside AR/MR may the record be labelled `LIKELY_E_NOT_AR_PENDING_PRIMARY_REVIEW`.
7. Never write an official exclusion without a genuine primary reviewer decision.
8. Feed rescued terminology back into the assistance rule, but preserve the original Run 60 output for provenance.
