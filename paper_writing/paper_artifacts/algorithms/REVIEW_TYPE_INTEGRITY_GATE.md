# Algorithm — Review-Type Integrity Gate

1. Ask whether the article claims systematic/exhaustive database retrieval.
2. If YES, require source-native formal execution provenance for the declared databases or explicit documented limitations.
3. If formal execution provenance is incomplete, block PRISMA counts and final systematic-corpus Results.
4. Never substitute general web discovery for an undeclared formal database execution.
5. If the author elects to proceed without formal source access, activate Path E:
   - remove “systematic review” claims from title/abstract/method;
   - describe the corpus as curated/structured;
   - prohibit prevalence/exhaustiveness claims;
   - preserve the abandoned systematic protocol and amendment record.
6. Only one path may govern the final paper.
