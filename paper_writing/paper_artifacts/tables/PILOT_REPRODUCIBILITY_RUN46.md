# Pilot Reproducibility Audit — Run 46

S0001 records code availability as yes, data not applicable and configuration partial. For many other studies, code/data/configuration remain unknown or partial. Hardware is often named, but named hardware alone does not establish executable reproducibility. Open full text is not scored as code/data/environment availability.

A final R-level distribution is not computed from incomplete fields.

Unknown ≠ unavailable. Unavailable ≠ irreproducible. Reported artifact ≠ successfully reproduced. Reproduction ≠ independent replication.
