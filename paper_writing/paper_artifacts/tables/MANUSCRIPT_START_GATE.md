# Manuscript Start Gate — What Can Be Written Before vs After Corpus Freeze

| Manuscript component | Can draft now? | Freeze-dependent content | Rule |
|---|---:|---|---|
| Problem framing / AR scope | YES | final corpus-derived prevalence statements | cite validated prior literature only |
| Prior reviews / positioning | YES | final comparison against included review corpus | no broadness-only novelty claim |
| Contributions | YES, provisional | final evidence-supported contribution wording | no novelty claim beyond verified evidence |
| Protocol / search design | YES | exact executed query strings, dates and counts | planned != executed |
| Deduplication method | YES | actual duplicate counts/adjudications | method may be written; results may not |
| Screening / eligibility method | YES | exclusion counts and final included n | no PRISMA numbers before freeze |
| Extraction/evidence model | YES | final coded frequencies | schema != empirical distribution |
| Results | NO final results | all corpus-derived counts/tables | wait for freeze |
| Discussion | outline only | strength/contradiction/gap conclusions | wait for synthesis |
| PRISMA figure | NO | exact reconciled counts | derive from ledgers only |

## Start decision
A **Methods-first manuscript skeleton can be opened now** without fabricating results. The final Introduction/Methods can be locked after formal execution and corpus freeze. Results remain blocked.

## Required language boundary
Use “we planned / the protocol specifies” for unexecuted search operations. Use “we searched / retrieved / included” only after provenance-backed execution.
