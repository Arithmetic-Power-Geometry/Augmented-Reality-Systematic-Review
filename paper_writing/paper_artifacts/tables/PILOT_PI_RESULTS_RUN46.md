# Pilot P_i Extraction Results — Run 46

All 16 seed studies map to P_i=(D,T,H,S,A,M,E,U,R).

| Structural observation | Pilot evidence | Interpretation |
|---|---|---|
| Domain heterogeneity | security, interaction, accessibility, education, industrial, digital twin, tracking, urban planning, human factors | a single field-wide effect size is inappropriate |
| Technology/hardware heterogeneity | multi-platform AR, HoloLens/HoloLens 2, spatial AR, mobile AR, smartphone LiDAR/GNSS | hardware is part of the evidence condition |
| Sensing heterogeneity | gaze/gesture/speech, EEG, eye tracking, vSLAM, camera, LiDAR/GNSS | sensing changes capability and evaluator semantics |
| Metric heterogeneity | attack success, localization, workload, usability, task performance, communication delay | metrics require task-family interpretation |
| User heterogeneity | children, people with disabilities, employees/operators, general participants, system-only evaluations | population/context must be retained |
| Reproducibility heterogeneity | code known for S0001; many code/data/config fields unknown; full-text access varies | access is not equivalent to reproducibility |

These are properties observed in the 16-study pilot, not population-frequency claims about AR research.
