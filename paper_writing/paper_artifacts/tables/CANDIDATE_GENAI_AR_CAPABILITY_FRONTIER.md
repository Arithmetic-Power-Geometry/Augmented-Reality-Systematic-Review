# Candidate Result — Generative-AI AR Capability Frontier

**Pre-freeze synthesis and novelty-control artifact.**

Validated 2025 primary systems already occupy several distinct capability classes:

| System | Primary capability | Context/adaptation | Agent role |
|---|---|---|---|
| CARING-AI | generate and author situated AR instructions/avatar demonstrations | human/environment/system context | GenAI content authoring |
| Satori | proactive task assistance | actions + goals + objects + environment + BDI user state | LLM/local-model proactive assistant |
| SocialMind | in-situ live social assistance | verbal/nonverbal multimodal social context | proactive social assistant |
| agentAR | create AR applications | tool-augmented application-generation workflow | autonomous LLM-based agent |

## Novelty consequence
The following are **not sufficient novelty claims**:
- “we combine an LLM with AR”;
- “we make AR context-aware with GenAI”;
- “we provide proactive AR assistance”;
- “an autonomous LLM agent creates AR content/applications.”

Any P3 method must survive direct comparison with these capability classes plus the 2025 XR–LLM review corpus. A possible unresolved space may involve verified multi-objective runtime orchestration across compute/network/privacy/energy/task/user state, but that remains a hypothesis only.
